# 8. Future Improvements

## File Purpose
This document captures the planned production hardening and feature extensions for later iterations.

- Real OAuth2 identity provider integration.
- Kafka consumer group implementation for delayed delivery.
- Persistent Redis-based rate limiting.
- Mongo audit write-through service.
- PDF and CSV export endpoints.
- Leave management integration.
- Calendar sync for Microsoft 365 and Google Calendar.
- Slack and Microsoft Teams outbound adapters.
- Mobile-responsive PWA dashboard support.
- AI burnout prediction model.
- Emergency override approval workflow.
